# Artwork

PNG files placed here are applied to the Steam library entry by `install.sh`. Any missing file is skipped.

| File | Steam usage | Recommended size |
| --- | --- | --- |
| `cover.png` | Library cover (portrait capsule) | 600x900 |
| `wide.png` | Wide capsule (recent games, shelves) | 920x430 |
| `hero.png` | Banner at the top of the game page | 1920x620 |
| `logo.png` | Logo shown over the hero banner (transparent background) | about 1280x720 max |
| `icon.png` | Small icon in the library list and launcher | 256x256 |

Only add artwork you created yourself or have permission to use. Super Museum and its art belong to livercake.
